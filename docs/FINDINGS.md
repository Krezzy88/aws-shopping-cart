## Baseline notes

- The working tree was clean before the upgrade branch was created.
- Baseline was Java 21, Spring Boot 4.0.1, and Gradle 9.2.1. The current working tree uses Spring Boot 4.0.9 after the image scan found critical dependency vulnerabilities.
- At baseline, `.github/workflows/ci-cd.yaml` ran only on pushes to `main`, used version-tagged Actions, and deployed to one EC2 instance without scans or readiness-based rollback. The current workflow changes are summarized in F-04 through F-06.
- The schema and seed data are in `src/main/resources/db/re_shopping_cart_db.sql`; the app expects an external MySQL connection.
- No license file is present. `.env.example` is the only tracked `.env*` file.
- Docker was unavailable during the initial baseline, but subsequent Compose build/startup, readiness, non-root runtime identity, and image scan were verified locally; see `docs/EVIDENCE.md`.
- The repo uses a GitHub-hosted CI runner for SSH deploy, while Terraform restricts inbound SSH to a configured CIDR. A fixed personal CIDR will not match GitHub-hosted runner egress; deployment needs controlled static egress or an SSM redesign. Do not open SSH globally to bridge this mismatch.
- No AWS resources or credentials were accessed.
